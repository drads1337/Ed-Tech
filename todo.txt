FRONTEND ROADMAP / TODO

Build the mock-data frontend step by step in the cozy cartoon neobrutalism style from:

============================================================
PHASE 2. SOLO MVP LOOP
============================================================

Status: TODO

Goal:
Build one complete individual user flow:
Choose goal -> see roadmap -> start practice -> get feedback.

Screens:
1. Solo Onboarding
   - Goal selection:
     - Job interview
     - Sales calls
     - Customer support
     - Public speaking
     - Difficult conversations
     - Exam / oral defense
   - Difficulty:
     - Easy: supportive coach
     - Medium: realistic pressure
     - Hard: stressful roleplay
   - Daily practice time:
     - 5 minutes
     - 15 minutes
     - 30 minutes
   - Generate my plan button.

2. Solo Dashboard
   - Streak, XP, current level.
   - Today's practice card.
   - Hardcoded AI-looking roadmap:
     - Warm-up conversation
     - Handling pressure
     - Objection / conflict
     - Final challenge
   - Progress section:
     - Confidence score
     - Communication score
     - Weakest skill
     - Better than yesterday message

3. Solo Practice Session
   - Reuse the existing 3D scene as the hero area.
   - Scenario title.
   - AI persona.
   - AI message.
   - User text input.
   - Send button.
   - Voice button can be visual only.
   - Hint buttons:
     - Ask clarification
     - Calm the person
     - Use stronger argument
   - Live indicators:
     - AI pressure level
     - User confidence level
     - Session progress

4. Solo Feedback
   - Total score.
   - What went well.
   - What needs improvement.
   - Best next step.
   - Skill scores:
     - Confidence
     - Structure
     - Accuracy
     - Empathy
     - Objection handling
   - Transcript review.
   - Retry weak spot / Next scenario / Back to dashboard buttons.

Mock behavior:
- Onboarding choices update displayed roadmap/scenario text.
- Text input adds a message to transcript.
- Ending the session shows a hardcoded feedback result.

Done when:
- Solo path feels demoable from start to finish.
- No backend or real AI required.
